# Proxy Sait

Каталог Telegram MTProto-прокси с поиском, фильтрами и копированием ссылки подключения.

## Автообновление

Worker объединяет два публичных источника:
- iwizard7/MTProxy_list — data/working.txt (real MTProto handshake verified)
- 0xRadikal/Free-Telegram-Proxy — fast/tg.txt

Дубликаты удаляются по серверу и порту. Каждый адрес дополнительно проходит TCP-проверку. Источники сами выполняют настоящий MTProto handshake; это важнее простой проверки открытого порта. Endpoint `/proxies.txt` выдаёт только свежие записи со статусом `online`. Если один источник временно недоступен, его предыдущие записи сохраняются и проверяются повторно; если оба источника недоступны, предыдущий каталог не стирается.

Обновление запускается каждые 5 часов. Состояние и время проверки хранятся в Cloudflare D1.

Важно: TCP-проверка подтверждает доступность порта, но не гарантирует, что прокси будет стабильно работать в Telegram. Публичные прокси принадлежат третьим лицам; не передавай через них конфиденциальную информацию.

## Деплой

```bash
npm install --save-dev wrangler
npx wrangler login
npx wrangler d1 migrations apply steklovpn-shared --remote
npx wrangler deploy
```

Исходный код Worker — `src/worker.js`, статические файлы — `public/`, миграции D1 — `migrations/`.
