# Proxy Sait

Каталог Telegram MTProto-прокси с поиском, фильтрами и копированием ссылок подключения. Worker автоматически получает списки из двух независимых источников, объединяет их и дополнительно проверяет доступность серверов.

## Источники

- [iwizard7 — stable.txt](https://iwizard7.github.io/MTProxy_list/stable.txt): прокси, прошедшие настоящий MTProto handshake в течение последних 24 часов.
- [0xRadikal — stable/tg.txt](https://raw.githubusercontent.com/0xRadikal/Free-Telegram-Proxy/main/stable/tg.txt): прокси, прошедшие реальные MTProto-проверки и имеющие не менее 90% успешных недавних проверок.

Оба источника автоматически обновляются своими проектами. Worker загружает их каждые 5 часов, объединяет списки и удаляет дубликаты. После этого выполняется дополнительная TCP-проверка. Важно: локальная TCP-проверка показывает доступность порта, а подтверждение MTProto relay берётся из проверок самих источников.

Если один источник временно недоступен, используется второй. Если недоступны оба источника или ни один кандидат не проходит дополнительную проверку, прежний кэш не очищается.

## Обновление

Cloudflare Cron запускает обновление каждые 5 часов: `0 */5 * * *`. Результаты проверки сохраняются в D1 (`steklovpn-shared`).

## Деплой

```bash
npm install
npx wrangler login
npx wrangler d1 migrations apply steklovpn-shared --remote
npx wrangler deploy
```

Публичные прокси принадлежат сторонним операторам. Их доступность не гарантируется, а оператор может видеть метаданные соединения. Не используй неизвестные прокси для передачи конфиденциальной информации.
